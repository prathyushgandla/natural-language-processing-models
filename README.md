Machine Learning & NLP Projects

This repository contains a collection of simple yet practical Machine Learning and Natural Language Processing (NLP) projects. Each project is designed to be beginner-friendly while showcasing essential concepts in text processing, model building, evaluation, and deployment.

The primary focus of these projects is to demonstrate how ML can be applied to real-world text-based problems such as classification, sentiment analysis, and spam detection.

Featured Project: Spam Detection (Email/SMS)

1.The Spam Detection Project applies NLP techniques and classical machine learning algorithms to classify messages as Spam or Ham (Not Spam).

Key Features

Preprocessing:

1.Text cleaning
2.Tokenization
3.Stopword removal
4.Lemmatization
5.TF-IDF vectorization

Algorithms used:
1.Naive Bayes
2.KNeighborsClassifier

Model evaluation metrics:
1.Accuracy
2.Precision
3.Recall
4.F1-score

Includes Jupyter Notebook with step-by-step implementation
